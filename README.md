# **Supply Runner**

This repository contains the C# scripts and the game design document for **Supply Runner**, a full-stack game developed using the **Unity Engine** and **C#**.

## **About the Project**
**Supply Runner** is a game created to explore and showcase gameplay mechanics, scripting, and game design. While the full game is not included in this repository, the essential scripts and the game design document provide an in-depth look at the development process.

### **Features**
- Written entirely in **C#**.
- Designed and developed with gameplay mechanics and player experience in mind.
- Game design document outlining the vision, mechanics, and design of the game.

## **Repository Contents**
